# HTML 精排版 · 构建指南

用于「HTML 精排」路径：把观察结果填入 HTML 模板，用 Chrome 截图为真正的 16:9 PNG。
优点：中文文字清晰可读、HEX 色值准确、引线锚点位置可控、可复现。

## 画幅与栅格

- 画布固定 1920×1080（16:9）。渲染脚本按此尺寸截图。
- 背景：深墨绿 `#0f2b26` / 炭黑 `#121715`；标签：低饱和鼠尾草绿 `#8fae9b`；正文：白 `#f2f5f3` / 浅灰 `#b7c2bd`。
- 建议栅格（可用 CSS Grid 微调）：
  - 顶部标题条 ~60px
  - 主区 ~640px：左 58% = 模块 A 原图；右 42% = 模块 B 关键词 + 模块 C 构图
  - 中下条 ~220px：模块 D 细节缩略图（约 45%）+ 模块 E 光影（约 25%）+ 模块 F 色卡（约 30%）
  - 底部条 ~128px：模块 G 中英文提示词（左右两栏）
  - 行间距约 12px

> 七大模块是内容结构不是死框。文字多就压缩冗余描述，不要缩到看不清。

## 逐模块填充要点

| 模块 | 数据来源 | 填充要点 |
|------|----------|----------|
| A 原图标注 | 视觉观察 | 原图用 `<img>` 完整展示（object-fit: contain，保留比例），不要裁剪主体。5–8 个锚点用绝对定位的圆形小点 + SVG/绝对定位引线，引线终点对准真实位置。标注卡片半透明深色，文字 ≤ 两行。 |
| B 关键词 | 视觉观察 | 7–9 行，绿色胶囊 + 右侧描述。描述写"具体可见特征"，不写形容词堆砌。 |
| C 构图线稿 | 视觉观察 | 用内嵌 SVG 画：浅灰白底、深灰主体轮廓、淡红辅助线（三分线/消失点等只画相关的）。线稿旁两段文字「构图要点」「机位与镜头」。相机参数不确定时写"推测/视觉上接近"。 |
| D 细节参考 | analyze_photo.py 生成的裁切图 | 约 5 张缩略图，来自真实裁切；每张中文标题 + 一句解释。避免重复相似区域。 |
| E 光影色彩 | 视觉观察 | 绿色小标签 + 说明；按场景自适应维度；不虚构灯具。 |
| F 配色 | analyze_photo.py 的 palette JSON | 6 张纵向色卡，HEX + 中文色名 + 用途说明。无法精确采样标注"近似"。黑白照不要硬凑鲜艳色。 |
| G 反推提示词 | 视觉观察综合 | 中文 + English 两段，忠实复刻原图，不添加不存在元素。用小字号但保证可读（≥ 13px）。 |

## 锚点与引线技巧

- **竖图（如 9:16 人像）**：`<img>` 会按 contain 居中并在两侧留空，锚点不要直接按容器百分比定位（会错位）。改用与图片精确贴合的 `.photo-stage`（`position:relative; display:inline-block; height:100%`，内部 `<img style="height:100%;width:auto">`），在其上叠一个 `viewBox` 等于原图像素尺寸的 SVG（`preserveAspectRatio="xMidYMid meet"`、`overflow:visible`），锚点和标签全部用原图坐标写在该 SVG 内。这样引线终点与画面元素严格对齐。
- 标签卡片放在图片左右两侧留白处（左侧 x 为负、右侧 x 大于图宽），避免压住核心主体。**每个标签的注释文字必须短到能塞进卡片宽度**（实测 SVG 卡片宽 84 单位、字号 6.8 时，中文注释控制在 ~10 字以内；超长文字会溢出到图片上）。
- 用一个与图片同尺寸的透明覆盖层 `<div class="overlay">` 包裹 `<img>`，锚点用百分比定位（如 `left: 62%; top: 34%`），这样换图/缩放不错位。
- 引线用 SVG `<line>` 或细边框 div，从锚点连到旁边的标注卡片；线宽 1px、白色半透明。
- 标注卡片尽量放在图片边缘或留白处，避免压住核心主体。

## 质量控制（截图前逐项确认）

1. 原图完整、保真，比例未被拉伸。
2. 所有引线/锚点对准真实画面元素。
3. 构图线稿对应原图，辅助线不是乱叠加。
4. 5 张细节来自原图且不重复。
5. 6 张色卡 HEX 来自真实采样或标注近似。
6. 没有无法证实的摄影参数被写成事实。
7. 中英文提示词忠实原图、文字可读（无溢出/遮挡）。
8. 整体风格统一、留白充分、层级清晰。
